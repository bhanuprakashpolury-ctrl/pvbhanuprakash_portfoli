# PVN Bhanuprakash — Professional Brand Website

A recruiter-focused personal brand website for PVN Bhanuprakash, built from the uploaded resume.

## What is included

- Premium responsive personal-brand landing page
- Automation / QA positioning
- Career timeline from 2011 to present
- Expertise cards
- Technology stack
- Education and continuous-learning section
- Email and phone links
- Downloadable resume
- GitHub and LinkedIn profile placeholders
- Social/SEO metadata
- Plain HTML/CSS — no build system required

## GitHub repository

Recommended repository name:

`bhanuprakash-portfolio`

Recommended structure:

```text
bhanuprakash-portfolio/
├── index.html
├── styles.css
├── README.md
├── assets/
│   └── PVN-Bhanuprakash-Resume.pdf
└── resume/
    └── PVN-Bhanuprakash-Resume.pdf
```

## IMPORTANT: Add your actual profile links

The website currently uses safe placeholders because your actual GitHub and LinkedIn URLs were not provided.

In `index.html`, replace:

- `https://github.com/`
- `https://www.linkedin.com/`

with your actual profile URLs.

## Deploy to Vercel

1. Create a GitHub repository named `bhanuprakash-portfolio`.
2. Upload all files from this folder.
3. Import the repository into Vercel.
4. Framework: Other / static site.
5. Build command: empty.
6. Output directory: `.`
